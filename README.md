\# TManhios Key Generator



Web tĩnh sinh key format `TManhios-1Day-XXXXXXXXXX`.



\## Cách dùng

1\. Mở `index.html` hoặc truy cập GitHub Pages.

2\. Nhập số lượng key cần tạo.

3\. Bấm TẠO KEY.

4\. Bấm COPY TẤT CẢ để lấy danh sách.



\## Deploy GitHub Pages

1\. Tạo repo mới trên GitHub.

2\. Upload toàn bộ file.

3\. Vào Settings → Pages → Source: main branch / root.

4\. Truy cập `https://username.github.io/repo-name/`.
